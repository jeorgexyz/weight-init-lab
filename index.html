Weight Init Lab

An interactive guide to neural network weight initialization. Before a neural network learns anything, every weight gets a random number. Pick those numbers badly and the network can't learn at all. This page lets you see why, and how Xavier, He and related schemes fix it.

Why the first numbers matter

A deep network is a long chain of matrix multiplications with a squashing function between each one. Each layer multiplies its input by a weight matrix, so whatever scale the weights have gets multiplied in again and again. A scale slightly too small and the signal shrinks toward zero by the tenth layer. Slightly too large and it explodes, or slams every tanh unit into its flat ±1 region where nothing can change.

The same thing happens in reverse during backpropagation. Gradients travel back through the same weights, so they vanish or explode the same way. When gradients vanish, the early layers stop learning. The goal of a good initialization is simple to state: keep the size of the signal roughly constant from layer to layer, in both directions.

Where the formulas come from

The derivation behind Xavier initialization is short enough to follow in four steps. Take one layer that computes z = Wx, where each output sums over nin inputs.

  1. Assume the weights and inputs are independent, with mean zero. The variance of a product of independent zero-mean variables is the product of their variances, and variances add over a sum. So each output's variance is:

    Var(z) = nin · Var(w) · Var(x)

  2. For the signal to keep its size going forward, we need Var(z) = Var(x), which means:

    Var(w) = 1 / nin LeCun initialization, from 1998

  3. Run the same argument backward. The gradient reaching each input is a sum over nout outputs, so keeping gradients steady requires Var(w) = 1 / nout. Unless the layer is square you can't satisfy both, so Glorot and Bengio (2010) took the average:

    Var(w) = 2 / (nin + nout) Xavier / Glorot. For a uniform U(−a, a), a = √(6 / (nin + nout))

  4. This analysis treats the activation as roughly linear near zero, which holds for tanh. ReLU breaks it: it zeroes out half of its inputs, so it throws away half the signal's energy at every layer. He et al. (2015) doubled the variance to compensate:

    Var(w) = 2 / nin He / Kaiming initialization, for ReLU

Sigmoid is the awkward one. Its outputs are centered on 0.5, not zero, and its slope is at most 0.25, so every layer shrinks the gradient by at least a factor of four no matter how the weights are scaled. That is a large part of why deep networks moved away from it.

What to take away

Initialization is about variance, not about the particular random values. Keep each layer's output variance close to its input variance, forward and backward, and a deep network starts in a place where gradients can reach every layer.

Match the scheme to the activation: Xavier for tanh and other functions that look linear near zero, He for ReLU and its relatives. Modern tools like batch normalization, layer normalization and residual connections make networks far more forgiving, but they all lean on the same idea, and a bad starting scale can still waste hours of training.
